How a run works运作方式

Every decision keeps its paper trail.每一个决策，都留有完整的推理记录。

01 Gather收集 {{ landing.n_base }} analysts — {{ landing.n_astock }} for A-shares — each write a report from data dated to the run: prices, filings, estimates, news and sentiment. {{ landing.n_base }} 位分析师（A 股为 {{ landing.n_astock }} 位）各自基于截至分析日期的数据撰写报告：价格、财报、盈利预期、新闻与情绪。
02 Debate辩论 A bull and a bear argue over those reports for {{ rounds }} rounds. A research manager rules and writes the plan. 看涨与看跌研究员围绕这些报告辩论 {{ rounds }} 轮，由研究主管裁决并撰写投资计划。
03 Plan计划 The trader turns the plan into a proposal: a direction, an entry and a stop stated as prices, and a size. 交易员把计划变成具体方案：方向、以价格表示的入场位与止损位，以及仓位。
04 Stress-test压力测试 Aggressive, conservative and neutral risk analysts attack the proposal from three sides for {{ risk_rounds }} rounds. 激进、保守、中立三位风险分析师从三个方向质询方案，共 {{ risk_rounds }} 轮。
05 Decide决策 The portfolio manager signs one rating — Buy, Overweight, Hold, Underweight or Sell — with the reasoning attached. 投资组合经理签发唯一评级——买入、增持、持有、减持或卖出——并附上理由。

The desk投研团队

Every seat has a name. Every turn is on the record.每个席位都有名字，每一轮发言都有记录。

A report is drawn as a conversation between these roles, in the order they spoke — so you can read the bear's best argument before you read the verdict. 报告按照这些角色的发言顺序以对话形式呈现——你可以在看结论之前，先读完看跌研究员最有力的论点。
