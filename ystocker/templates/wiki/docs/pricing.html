What counts as a run怎样算一次

  • One analysis is one run, free or purchased, whatever model and thinking depth you choose, and whether it is a US or an A-share run. The allowances count runs, not model tokens.
  • It counts when you press Run, not when the run finishes — a queued run has already been counted.
  • Reading costs nothing. Opening your reports, downloading PDFs and opening a shared link never use a run.
  • Follow-up questions have their own allowance — {{ facts.chat_limit }} a day — and never draw on your runs. Sharing has its own too: up to {{ facts.share_limit }} shares a day.
  • 一次分析就是一次，无论用的是免费次数还是购买的次数，无论选择哪个模型、哪种思考深度，也无论分析的是美股还是 A 股。额度按分析次数计算，而不是按模型 token 计算。
  • 点击运行时即计数，而不是等分析完成——排队中的任务已经计入。
  • 阅读不花钱。打开自己的报告、下载 PDF、打开分享链接，都不消耗次数。
  • 追问有单独的额度——每天 {{ facts.chat_limit }} 次——不会占用分析次数。分享同样单独计算：每天最多 {{ facts.share_limit }} 次。

When a run is given back哪些情况会退还

A run that is given back returns to where it came from: today's free allowance, or your credit balance.

  • Refused at the door. The server rejects the request before queuing it — a ticker or date it cannot read, a date after today, or a model that is not available here.
  • Never started. The run waited too long for a free slot, or the analysis engine could not be started.
  • Out of model capacity. The model provider's daily capacity ran out and the run ended with no report at all.
  • No price data. The ticker has no price history on Yahoo Finance, so the run stopped at its first price lookup: usually a typo, an index, or a listing outside the US typed without its exchange suffix (TCS.NS rather than TCS). The page says what to type instead.

Anything else is not given back: once the analysis has started, an unknown number of model calls may already have been paid for. That covers a run that fails partway and one stopped by its time limit.

退还的次数会回到原来的地方：当天的免费额度，或者你购买的余额。

  • 请求被拒。服务器在排队前就拒绝了请求——代码或日期无法识别、日期晚于今天，或者所选模型在本站不可用。
  • 没有启动。等待空闲位置的时间过长，或者分析引擎无法启动。
  • 模型额度耗尽。模型服务商当天的额度用完，分析结束时没有产出任何报告。
  • 没有价格数据。该代码在雅虎财经上没有价格数据，分析在第一次查询价格时就停止了：通常是输错了代码、输入的是指数，或者美国以外的股票没有加交易所后缀（应输入 TCS.NS 而不是 TCS）。页面会提示应该输入什么。

其他情况一律不退：分析一旦开始，就可能已经产生了数量不定、且已付费的模型调用。这包括中途失败的分析，以及因超时被终止的分析。

The site-wide daily limit全站每日上限

Separately from your own allowance, the whole site runs at most {{ facts.global_runs }} analyses a day, across every account. Purchased runs count toward it too. It is a limit on what the server and its model quota can deliver in a day, not a billing rule, so buying a pack cannot raise it.

When it is reached, the run form says so and offers no pack, since there is no capacity left to sell. Your own free runs and credits are untouched, and runs start again after midnight{% if pacific %} Pacific time{% else %} ({{ facts.quota_tz }}){% endif %}.

在个人额度之外，全站所有账号加起来每天最多运行 {{ facts.global_runs }} 次分析，购买的次数同样计入。这是服务器和模型配额每天能承担的容量上限，不是计费规则，所以购买次数包并不能提高它。

达到上限时，分析表单会给出提示，并且不会推荐购买——因为已经没有容量可卖。你自己的免费次数和已购次数都不受影响，{% if pacific %}太平洋时间{% else %}{{ facts.quota_tz }} {% endif %}零点过后即可继续运行。
