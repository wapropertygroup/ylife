Your first run第一次运行

  1. Sign in with Google. Sign in and you are brought straight back to the run form. Every run makes paid model calls, so the form is for signed-in accounts only, and each account gets {{ facts.free_runs }} free runs a day.
  2. Enter a ticker. A US symbol such as NVDA, an ADR such as TSM, or a six-digit China A-share code such as 600519. What the box accepts is below.
  3. Pick the analysis date. It starts on today. An earlier date asks the desk to work from what was known that day, as far as each source can say — see Dated to the run. A date after today is refused before anything is queued, and costs nothing.

  4. Choose a model and thinking depth, or keep the defaults. The page remembers your choice on this browser, and Models and thinking depth compares them. The report is written in the page's language: switch with the 中文 / EN button in the header before you start, because the language is fixed the moment you press Run.
    5. {% else %}
  5. Check the model and language. Model choice is switched off at the moment, so every run uses the server's default, named under the form. The report is written in the page's language: switch with the 中文 / EN button in the header before you start, because the language is fixed the moment you press Run.
    6. {% endif %}
  6. Press ▶ Run analysis. The run shows as queued, then running, and each agent's section appears as that agent finishes. You can close the tab: when the run finishes, the report is emailed to the address you signed in with.

What the ticker box accepts代码格式

  • US listings and ADRs — letters, optionally followed by digits, a dot or a hyphen: NVDA, TSM, BRK-B. Case does not matter. Use Yahoo Finance's spelling for a share class, BRK-B rather than BRK.B: the symbol reaches the data sources as you typed it.
  • China A-shares — six digits, bare or with an exchange marker: 600519, SH600519, 600519.SS or 600519.SH for Shanghai, SZ / .SZ for Shenzhen, BJ / .BJ for Beijing. Any of these seats the {{ facts.n_astock - facts.n_base }} A-share specialists.
  • Not accepted — any other symbol that starts with a digit, such as Hong Kong's 0700.HK or Tokyo's 7203.T, and symbols with characters other than letters, digits, dots and hyphens, such as ^GSPC. The form refuses them and nothing is charged.

The form checks a symbol's shape, not whether the company exists. A symbol that looks right but has no data behind it — a typo, say — still starts a run and uses it up, and the analysts will report that they found nothing. Markets and data has the full list, and where each analyst's evidence comes from.

  • 美股与 ADR——以字母开头，后面可以跟数字、点号或连字符：NVDA、TSM、BRK-B。不区分大小写。股票类别请按 Yahoo Finance 的写法，用 BRK-B 而不是 BRK.B：代码会按你输入的原样交给数据源。
  • A 股——6 位数字，可以不加前后缀，也可以标明交易所：沪市写 600519、SH600519、600519.SS 或 600519.SH；深市用 SZ 前缀或 .SZ 后缀；北交所用 BJ 前缀或 .BJ 后缀。以上任何一种写法，都会加入 {{ facts.n_astock - facts.n_base }} 位 A 股专项分析师。
  • 不支持——其他以数字开头的代码，比如港股 0700.HK、东京的 7203.T；以及含有字母、数字、点号、连字符以外字符的代码，比如 ^GSPC。表单会直接拒绝，不扣任何次数。

表单只检查代码的格式，不检查这家公司是否存在。格式正确但背后没有数据的代码——比如输错了——照样会启动分析并消耗一次额度，分析师只会报告“查无数据”。完整的格式清单，以及每位分析师的证据来自哪里，见市场与数据。

While it runs运行期间

  • It may queue first. If the server is busy with other runs, yours waits as queued and starts when a slot frees up.
  • Sections stream in. The analysts' reports arrive one by one, then the debate, the trader's proposal and the risk debate, with the decision last — so you can start reading long before the end.
  • Nothing is lost if you leave. Closing the tab does not stop the run. Reopen it from Recent runs, or wait for the email.
  • 可能要先排队。如果服务器正在处理其他分析，你的任务会显示为排队，等空出位置后再开始。
  • 内容边写边出。分析师报告逐份出现，接着是多空辩论、交易员方案和风险辩论，最终决策最后出现——不必等到结束就可以开始阅读。
  • 离开页面也不会丢。关掉页面不会中止分析。之后可以从“最近运行”重新打开，或者等邮件通知。

When it finishes分析完成之后

  • Read it. The decision — one of Buy, Overweight, Hold, Underweight or Sell — sits at the top, then the report as a conversation, one turn per agent, with a bar for jumping between speakers.
  • Find it again. Recent runs, under the form, lists your runs grouped by analysis date, newest first. Search by ticker or by date — 2026-09 finds every run dated September 2026 — and narrow by status. A search result carries each hit's portfolio-manager section, so calls can be compared without opening every report.
  • Keep it. ⬇ Download PDF on the report, or PDF in the list, saves the whole report with its charts.
  • Share it. The Share button beside your account sends a finished report by email, text or a WeChat QR code. The link opens without an account for {{ facts.share_days }} days, and you can revoke it sooner.
  • Question it. Under a finished report, ask the portfolio manager a follow-up. Answers come from that report alone, and say so when it does not cover the question. You get {{ facts.chat_limit }} questions a day, counted separately from runs.
  • 阅读。最上方是最终决策——买入、增持、持有、减持、卖出五选一；下面是以对话形式呈现的报告，每位智能体一轮发言，并有一条导航栏可以在发言人之间跳转。
  • 查找。表单下方的“最近运行”按分析日期分组列出你的分析，最新的在前。可以按代码或日期搜索——输入 2026-09 会找出分析日期在 2026 年 9 月的全部报告——也可以按状态筛选。搜索结果会直接附上每份报告中投资组合经理的发言，不用逐一打开就能对比结论。
  • 保存。在报告上点“⬇ 下载 PDF”，或在列表里点“PDF”，即可保存含图表的完整报告。
  • 分享。账号旁边的“分享”按钮可以通过邮件、短信或微信二维码发送已完成的报告。对方无需账号即可打开，链接有效期 {{ facts.share_days }} 天，你也可以提前撤回。
  • 追问。在已完成的报告下方，可以向投资组合经理追问。回答只依据这份报告；报告没有涉及的问题，它会直接说明。每天可以追问 {{ facts.chat_limit }} 次，与分析次数分开计算。
